# Application screenshots

Captured by the actual Playwright browser workflow against local PostgreSQL and
MongoDB. Rerun `npm run test:e2e` after seeding to refresh them.

- [Researcher dashboard](researcher-dashboard.png): report submission and ownership.
- [Completed report](report-after-payout.png): rejected/replacement patches, approved
  remediation, payout, status history, and audit trail.
- [Admin dashboard](admin-dashboard.png): summary view, payout ledger, component aggregation.

Screenshots contain only sanitized local demonstration data and public demo account
identifiers. Credentials and session cookies are not included.
